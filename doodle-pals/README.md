# Doodle Pals

A mod for **Minecraft 1.21.1 (Forge)** by **@Adryh01**: paint a creature in your Sketchbook,
give it eyes, and it comes to life in 3D. The colours you use decide its powers.

See [INSTALL.txt](INSTALL.txt). Build with Java 21 and Gradle 9.5: `gradle build`.
Textures and texts come from `tools/make.py`.
