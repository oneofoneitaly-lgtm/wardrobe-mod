# Aura — modpack Forge 1.21.1 di @Adryh01

Cinque mod originali che cambiano l'aspetto del gioco, tutte personalizzabili in-game da **Aura Studio**
(Shift destro oppure `/aura`). Istruzioni in [LEGGIMI.txt](LEGGIMI.txt).

- `src/<mod>/` codice e risorse di ogni mod (`menu` è anche la libreria comune)
- `tools/make_assets.py` rigenera grafica, icone e descrittori
- GitHub Actions compila, prova il gioco e salva pacchetti e schermate nel ramo `ci-out`
