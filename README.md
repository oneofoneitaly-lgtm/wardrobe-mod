# Mythoria

A fantasy content modpack for **Minecraft 1.21.1 (Forge)** by **@Adryh01**: creatures, 3D swords,
3D armor and 3D food, bought in an in-game market with Crowns.

| Mod | Content |
|-----|---------|
| `mythoria-core` | Crowns, wallet, market menu (key `M` or `/market`) |
| `mythoria-creatures` | Golden Griffin (tame, ride, fly) and Crystal Golem (boss) |
| `mythoria-weapons` | Phoenix Blade, Frost Fang, Storm Blade |
| `mythoria-armory` | Dragon Armor |
| `mythoria-feast` | Moon Apple, Fairy Cake, Dragon Drumstick, Elven Mead |

See [INSTALL.txt](INSTALL.txt) to install and play.

## Building

`gradle build` with Java 21 and Gradle 9.5. GitHub Actions builds the jars, starts a real Forge
client, plays through the content and saves screenshots on the `ci-out` branch.

All models and textures are generated by the scripts in `tools/` (`python3 tools/make.py`,
needs numpy and Pillow). Do not edit the generated files by hand.
